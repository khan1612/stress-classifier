# Student Stress Level Classifier

A Streamlit application that predicts a student's stress level using a trained machine learning model.

## Project Structure

```text
.
├── app.py
├── requirements.txt
├── stress_classifier_final.pkl
└── src
    ├── app.py
    ├── config.py
    ├── model_loader.py
    ├── prediction.py
    └── ui.py
```

## Setup

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```
